# 國小國語圈詞練習

這是一個可放在 GitHub Pages 的靜態網站，用來練習課本被老師圈起來的詞語。

## 使用方式

直接用瀏覽器開啟 `index.html`，或把整個資料夾推到 GitHub 後啟用 GitHub Pages。

功能：

- 顯示每一課的圈詞清單
- 點詞語可以用語音唸出來
- 可依課本順序測驗
- 可隨機跳著測驗
- 顯示課本圖片，方便核對圈詞

## 新增課別

1. 建立新的資料夾，例如 `國文/2年級/第2課`。
2. 把課本圖片放進該資料夾。
3. 編輯 `lessons.js`，在 `window.LESSONS` 陣列中新增一筆資料：

```js
{
  id: "g2-l2",
  subject: "國文",
  grade: "2年級",
  title: "第2課 課名",
  images: [
    "國文/2年級/第2課/photo1.jpg",
    "國文/2年級/第2課/photo2.jpg"
  ],
  words: [
    "第一個圈詞",
    "第二個圈詞"
  ]
}
```

`words` 的順序就是「課本順序測驗」的出題順序。

## 網站內管理圈詞

展開「管理圈詞」後，可以直接新增、修改、刪除目前課別的圈詞。這些變更會立即寫入網站內的 IndexedDB 資料庫，並同步保留 localStorage 備份，重新整理後仍會保留。

如果要讓所有裝置都使用同一份預設圈詞，請把確認後的圈詞同步更新到 `lessons.js`，再推送到 GitHub Pages。

圈詞排序：在「管理圈詞」每一列使用「上」「下」按鈕調整順序。課本順序測驗會照目前清單順序出題。

## 聽寫練習

右側「聽寫練習」會列出目前課別的生詞。可以選擇照順序或亂序，也可以選手動或自動。手動時按「開始唸」會唸第一個，之後按「下一個」才會繼續；自動時可設定間隔秒數，系統會依設定逐一朗讀。可以按「重唸目前」重複聽同一個生詞，確認後再按「下一個」；自動模式也能按「重唸目前」重新朗讀目前生詞。


## 網站內新增課別與圖片辨識

展開「課別資料 / 上傳圖片」後，可以修改目前課別名稱、年級、替換圖片或刪除課別，也可以輸入新課別名稱、年級並選擇多張課本圖片。按「新增課別」會先建立空白課別；按「新增並辨識圈詞」會先建立課別，再嘗試用瀏覽器端 OCR 辨識圖片文字，並把辨識到的候選詞加入圈詞清單。

OCR 只能先抓出候選詞，無法保證完全等同老師圈起來的詞。辨識後請用「管理圈詞」新增、刪除、修改與排序。

網站內新增的課別、圖片與圈詞會存在目前瀏覽器。若要讓所有裝置都看到同一份課別，需把整理完成的課別資料加入 `lessons.js` 後重新推送到 GitHub Pages。


資料保存：網站會使用瀏覽器 IndexedDB 保存你新增的課別、圖片、圈詞與排序，並保留固定 localStorage key 作備份與舊資料搬移。一般功能更新不會更換資料庫或備份 key，避免你每次更新網站後都要重新整理單詞。

播放標示：聽寫朗讀時，正在唸的圈詞會變成黃色，這一輪已唸過的圈詞會變成綠色；整輪結束或按停止後會恢復正常。

注音顯示：課名、圈詞清單、聽寫清單、管理清單與測驗選項會用內建注音字典顯示注音；新課若出現字典沒有的字，該字會先顯示原字，之後可再補注音字典。

## 雲端同步

網站已接 Firebase Authentication 與 Firestore。按「Google 登入同步」後，課別、圖片、圈詞與排序會同步到 `users/{uid}/study/lessons`，同一個 Google 帳號在不同裝置登入會讀取同一份資料。

Firestore Rules 建議使用：

```js
rules_version = "2";

service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{userId}/{document=**} {
      allow read, write: if request.auth != null && request.auth.uid == userId;
    }
  }
}
```

IndexedDB 與 localStorage 仍會保留為本機備份；如果未登入或雲端暫時失敗，已修改資料仍會先留在目前瀏覽器。
