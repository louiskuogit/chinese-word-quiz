# 國小國語圈詞練習

這是一個可放在 GitHub Pages 的靜態網站，用來練習課本被老師圈起來的詞語。

## 使用方式

直接用瀏覽器開啟 `index.html`，或把整個資料夾推到 GitHub 後啟用 GitHub Pages。

功能：

- 顯示每一課的圈詞清單
- 點詞語可以用語音唸出來
- 可依課本順序測驗
- 可隨機跳著測驗
- 顯示課本圖片，方便核對圈詞

## 新增課別

1. 建立新的資料夾，例如 `國文/2年級/第2課`。
2. 把課本圖片放進該資料夾。
3. 編輯 `lessons.js`，在 `window.LESSONS` 陣列中新增一筆資料：

```js
{
  id: "g2-l2",
  subject: "國文",
  grade: "2年級",
  title: "第2課 課名",
  images: [
    "國文/2年級/第2課/photo1.jpg",
    "國文/2年級/第2課/photo2.jpg"
  ],
  words: [
    "第一個圈詞",
    "第二個圈詞"
  ]
}
```

`words` 的順序就是「課本順序測驗」的出題順序。

## 網站內管理圈詞

展開「管理圈詞」後，可以直接新增、修改、刪除目前課別的圈詞。這些變更會存在目前瀏覽器的 localStorage，重新整理後仍會保留。

如果要讓所有裝置都使用同一份預設圈詞，請把確認後的圈詞同步更新到 `lessons.js`，再推送到 GitHub Pages。
